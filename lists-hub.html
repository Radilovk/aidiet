Редакция на каталожни списъци

Ръчно допълване и редакция на всички основни списъци за Plan Engine v2. Промените се записват като JSON и се импортират обратно в кода.

Работен процес

  1. Синхронизирай от кода: npm run lists:export
  2. Редактирай през редакторите по-долу или директно JSON в data/lists/
  3. Изтегли обновения JSON или запази файла
  4. Импортирай в JS: npm run lists:import
  5. Пусни тестове: node scripts/test-meal-dishes.mjs и npm run build:worker

Допълнително

KV overlay (ресторантски ястия, admin продукти) е отделен — не замества базовите списъци.
