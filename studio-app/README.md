# Приложение „XB-Studio“ (iPhone и Android)

Една обвивка за **всички студиа**. Показва живата страница за записване (`https://biocode.website/studio.html`), затова
новите функции стигат до клиентите **без нова версия от магазина**. Клиентът избира студио (или въвежда неговия код),
записва час и **телефонът сам му напомня 4 часа преди часа** (локално известие — без сървър, без интернет в момента).
Студиото може да покаже съобщение на клиентите си (банер в страницата) от admin → Настройки → Известие — то **не** е известие на телефона.
Админ панелът на студиото работи **само в браузър** на адреса му (в приложението е изключен — правило на Apple за скрити функции).

Не се ползват push известия, затова **не са нужни** Firebase, APNs ключове и сертификати за известия.

## Какво се прави веднъж (iPhone)

### 1. Apple Developer Program — $99 на година, **личен (Individual) акаунт**
Записване през приложението **Apple Developer** на iPhone → Enroll → Individual (Apple ID с двуфакторна защита +
документ със снимка; 1–2 дни). В магазина се вижда личното ти име. Подробности за личен акаунт (вкл. задължителния
статус „Trader“ по DSA за ЕС): **`APP-STORE-SUBMISSION.md`, раздел 1**.

### 2. Име и Bundle ID — реши ги ПРЕДИ следващата стъпка (Bundle ID не се сменя)
Сега са: **Bundle ID `com.biocode.studios`**, име **„XB-Studio“** (`studio-app/capacitor.config.json`:
`appId`, `appName`). Ако искаш други — смени ги там сега.

### 3. App Store Connect
1. **Bundle ID** — регистрира се автоматично: GitHub → Actions → „Студио приложение — Apple (App Store Connect)“ →
   действие `bundle-id` (след като си сложил секретите от точка 4). Ръчният начин: developer.apple.com → Identifiers → +.
2. https://appstoreconnect.apple.com → My Apps → **+ New App**: платформа iOS, име, език **Bulgarian**,
   Bundle ID — избираш регистрирания, SKU — каквото и да е (напр. `studio-1`).
3. Users and Access → **Integrations → App Store Connect API → +**: име „GitHub“, роля **Admin**. Изтегли
   `AuthKey_XXXX.p8` (дава се само веднъж!). Запиши **Key ID** и **Issuer ID** (най-горе на страницата).
4. GitHub → Settings → Secrets and variables → Actions → 4 нови секрета:
   | Секрет | Стойност |
   |---|---|
   | `APPLE_TEAM_ID` | developer.apple.com → Membership details → Team ID |
   | `APPSTORE_KEY_ID` | Key ID от стъпка 3 |
   | `APPSTORE_ISSUER_ID` | Issuer ID от стъпка 3 |
   | `APPSTORE_KEY_P8` | целият текст на `.p8` файла (с `-----BEGIN PRIVATE KEY-----`) |

### 4. Компилиране и качване — без Mac
Actions → **„Студио приложение — iOS (TestFlight)“** → Run workflow. Работи на облачен Mac на GitHub (безплатно за
публично репо), Xcode сам прави сертификата и профила чрез API ключа (без ръчно теглене на файлове). След 10–30
минути билдът е в App Store Connect → TestFlight. Добави себе си като вътрешен тестер и го инсталирай през
приложението TestFlight.

> Това не е изпробвано на истински Mac (тази среда е Linux). При първото пускане е възможна една-две дребни
> поправки в процеса — изпрати ми червения лог и ги оправям.

### 5. Подаване за ревю (App Store)
**Не подавай, преди да мине `TESTFLIGHT-CHECKLIST.md` на истински iPhone.** Всичко за подаването — одит по правилата на
Apple, отговори за App Store Connect, демо студио, текст за ревюиращия, скрийншоти, резервен план — е в
**`APP-STORE-SUBMISSION.md`**.

Накратко какво е направено, за да няма причини за връщане: няма скрити функции (админът е само в браузър), няма
известия за реклама (само напомняне за собствен час), има изтриване на данни в приложението, политика и страница за
помощ, манифест за поверителност в пакета, без проследяване, и демо студио за ревюиращия.

## Android
- Actions → **„Студио приложение — Android“** → Run workflow → от Artifacts свали `studio-app-apk` и го инсталирай на
  Android (разрешаваш „инсталиране от неизвестен източник“) — това е за пробване.
- **Google Play** (по желание, $25 еднократно): направи ключ веднъж и сложи 4 секрета:
  ```
  keytool -genkeypair -v -keystore studio.keystore -alias studio -keyalg RSA -keysize 2048 -validity 10000
  base64 -w0 studio.keystore    # → секрет STUDIO_KEYSTORE_BASE64
  ```
  Още: `STUDIO_KEYSTORE_PASSWORD`, `STUDIO_KEY_ALIAS` (= `studio`), `STUDIO_KEY_PASSWORD`. Пази файла на сигурно място.
  Workflow-ът дава и подписан `studio-app-aab` за качване в Play Console. (Play Console изисква и политика за
  поверителност — същият адрес.)

## Как работи (за разработка)
- `capacitor.config.json` — идентичност, адресът на страницата (`server.url`), плъгини. `www/` е само началният и
  офлайн екранът.
- `scripts/patch-ios.py`, `scripts/patch-android.py` — малките поправки върху генерирания проект (идемпотентни);
  `scripts/add-privacy-manifest.rb` + `ios-extra/PrivacyInfo.xcprivacy` — манифестът за поверителност на Apple.
- `assets/icon.png`, `assets/splash.png` — иконата е логото от PWA (`xbody-icon-512.png`), качено на 1024×1024 върху бял
  фон без прозрачност (изискване на Apple). За по-остра икона дай оригинал 1024×1024 и го сложи в `assets/icon.png`.
- Проектите `ios/` и `android/` не се пазят в репото — правят се наново при всяко пускане.
- Локално (на Mac): `cd studio-app && npm ci && npx cap add ios && python3 scripts/patch-ios.py && npx cap open ios`.

## Промени и обновления — свободно
- **Страницата** (`studio.html`, бекенд на студиата): промяна в `main` → стига до всички клиенти веднага, без нова
  версия от Apple. Преди това я проверява `studio-ui-check.yml` (клиент, admin и приложение в истински браузър).
  Не променяй предназначението на приложението (записване на часове в студиа) — Apple го следи.
- **Обвивката** (икона, име, плъгини): пуска се наново процесът „iOS (TestFlight)“, после „нова версия“ в App Store
  Connect (ревю 1–2 дни). Нужно е рядко.
- Докато версията е в ревю, не публикувай големи промени по страницата.

## Такси и правни въпроси (накратко)
- **Apple:** само $99 на година. Безплатно приложение; за услуги, ползвани на място и платени извън приложението
  (Guideline 3.1.3(e)), Apple **не взема комисионна**.
- **Плащания:** всяко студио е със **свой Stripe акаунт** — парите отиват директно при студиото, платформата не ги
  държи и не е платежен посредник. Такси на Stripe плаща студиото само когато реално тегли (напр. неявяване).
  Приложението само записва карта като гаранция (SetupIntent), без таксуване при записване.
- **Данни (GDPR):** студиата са администратор на данните на клиентите си, платформата е обработващ. Добре е да има
  кратко писмено споразумение със студио (Data Processing Agreement) — не е правен съвет; питай юрист за точния текст.
